# نموذج أولي لمنصة أكاديمية كرة القدم

واجهة عربية RTL مبنية بـ Next.js App Router. المشروع Frontend فقط: لا توجد قاعدة بيانات أو API أو مصادقة حقيقية.

## التشغيل والمسارات

يتطلب Node.js 20.9 أو أحدث.

```bash
npm install
npm run dev
```

افتح `http://localhost:3000` لصفحة الهبوط. زر «الدخول التجريبي» ينقل إلى `/login`، حيث تختار دور العرض ثم تستعرض الواجهة المناسبة.

## الأدوار ونطاق العرض

تتوفر أدوار مستقلة للمالك، ومدير الأكاديمية، والمدرب، وولي الأمر، واللاعب، ومدير المنصة. لا توجد كلمات مرور؛ اختيار الدور يحفظ حالة العرض في `sessionStorage`، وزر «تغيير الدور» ينهيها.

المالك يرى كل فروع أكاديميته ويستطيع اختيار فرع أو عرضها مجتمعة، مع أدوات إدارة المدير وإدارة الفروع. مدير الأكاديمية يرى بيانات أكاديميته كاملة ولا يصل إلى أكاديمية أخرى. بقية الأدوار تعرض بيانات الفريق أو اللاعب المرتبط بها. هذه حدود عرض داخل المتصفح فقط وليست حماية فعلية.

## البيانات التجريبية

- `src/data/models.ts`: أنواع البيانات المشتركة.
- `src/data/mock/mock-repository.ts`: بيانات الأكاديمية وعلاقات الفروع والفرق واللاعبين والحضور والتقييمات وخطط التطوير.
- `src/data/mock/mock-platform-repository.ts`: ملخصات إدارة المنصة عبر الأكاديميات.
- `src/auth/demo-session.ts`: حسابات العرض ونطاق كل دور.
- `src/data/repository-provider.ts`: اختيار مصدر بيانات الأكاديمية والمنصة.

تحتوي بيانات أكاديمية النخبة على 23 لاعباً، و6 فرق، و6 أعضاء طاقم، و3 فروع. أرقام لوحة مدير المنصة ملخصات تجريبية لأربع أكاديميات وليست سجلات تفصيلية كاملة لها. عمليات الإضافة والحفظ في الواجهات تغيّر حالة العرض في الذاكرة، ثم تعود البيانات الأصلية عند إعادة تحميل الصفحة.

تستخدم العلاقات معرّفات ثابتة: اللاعب مرتبط بالفريق عبر `teamId`، والهدف باللاعب عبر `playerId`، والجلسة بالفريق عبر `teamId`. حضور الجلسة وتقييماتها ليست بديلاً عن السجلات الموسمية المعروضة في ملف اللاعب.

## الانتقال إلى خدمات فعلية

1. أنشئ محول API/قاعدة بيانات يطبق `AcademyRepository`، ومحولاً منفصلاً يطبق `PlatformRepository`.
2. بدّل المصدرين في `src/data/repository-provider.ts`.
3. طبّق المصادقة وفحص الصلاحيات وعزل الأكاديمية والفرع على الخادم لكل طلب؛ لا تعتمد على نطاقات المستخدم القادمة من المتصفح.
4. انقل بيانات الأكاديمية والتقييمات والحضور والأهداف والتقارير وسجل النشاط إلى الخدمات الفعلية، ثم احذف بيانات ومصادقة العرض.

هذا النموذج لا يصلح لحفظ بيانات لاعبين حقيقية ولا يثبت وجود عزل أمني بين الأكاديميات.
